# Critical Care Universe

Six patients at once. A realistic command room, then the bedside.

Each bed has a moving four-channel monitor (pulse, arterial pressure, oxygen saturation, and respiratory rate) and, when NIV or a tube is actually on, a ventilator picture with pressure, flow, and volume. The chest of the gown rises. A call from another bed can arrive while you are already with someone.

This repository is separate from the one-bed simulator.

Open the site, enter the unit, and tap a screen.
